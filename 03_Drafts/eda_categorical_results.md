**Data quality issue found:** the `state` column is not clean. It contains **both two-letter abbreviations and full state names as separate categories** for the same state:

| Abbreviation | Count | Full Name Variant | Count |
|---|---|---|---|
| PA | 384 | Pennsylvania | 25 |
| NJ | 272 | New Jersey | 13 |
| NY | 264 | New York | 12 |
| FL | 128 | Florida | 14 |
| CA | 115 | California | 5 |
| IL | 78 | Illinois | 4 |
| TX | 132 | Texas | 2 |

This inflates the apparent number of distinct states from 20 to 27 and splits what should be a single group's loan count and statistics across two labels. Any state-level grouping (e.g., default rate by state) run on the raw column would understate the true totals for PA, NJ, NY, FL, CA, IL, and TX. **This should be standardized (e.g., map full names to abbreviations) before any state-level analysis.**

## Why This Matters Before Grouping

The full-name variants (Texas: 2, Illinois: 4, California: 5, New York: 12, New Jersey: 13, Florida: 14, Pennsylvania: 25) are themselves examples of unreliable small groups — but they're actually data-entry artifacts of the same states already counted under their abbreviations, not genuinely small state populations. Once the abbreviation/full-name variants are merged, every state has 30+ loans, so this dataset does not currently have a genuine small-sample-size problem at the state level — but it would be introduced artificially if the naming inconsistency isn't fixed first.
